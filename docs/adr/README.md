# Decisions this template made

One file per decision, in the format `docs/agents/domain.md` describes. They are
this product's: a niche the page set answers to, a component that departs from
the style on purpose, a dependency taken on for one feature.

The style's own decisions are not here and are not copied in. They live in
`docs/adr/` of tuanfront-end/claude-build-template-skills, beside the skill that
enforces each one, because a template that carried them would carry a record it
never took part in — and a stale copy of it a year later.
